## 7. Construction recipe and Phase 1 learning
1. Define one module-stable `BlankSurfaceDescriptor` (surfaceId, label,
   ambientSummary). `blankSurfacePublication` builds the neutral identity, null
   canvas/work and agent context plus empty capability inventories.
2. Compose `BlankSurface descriptor={descriptor}` inside the route's AppChrome.
   Supply optional children only for domain-owned behavior such as the existing
   IndexAgentConversation. No new bar, editor, projection host or provider is needed.
3. Mount beneath the existing AgentInteractionProvider; its publish hook owns
   bind/update/release. Keep the descriptor stable to avoid avoidable config updates.
4. Route admission, selected-World verification, auth and AppChrome route key remain
   App responsibilities. Choose actual domain behavior explicitly; the generic
   inert descriptor does not grant Index endpoint or document-authoring admission.
5. Use loadFocusOptions=false where the legacy lens has no consumer. Re-enable
   normal routes; an unvalidated retained focus is pending, never a verified empty
   or valid result. The pending request's cleanup ignores late success/failure.

Proven reuse: test-only inert-fixture identity uses exactly the same factory and
component, including StrictMode replacement, unmount/reentry and publication
validation. It adds no production feature. Configuration handles inert inventory
and composition; new authoring/domain routes still need their actual authorities.
No universal manifest, router/schema engine or fake durable/local draft was added.
The page is nonauthoring, so no shared editor/session is remounted by blank state.

Remaining coupling: App's route dispatch and selected-World admission remain
explicit; AppChrome labels/navigation are independently owned; legacy compatibility
fixtures remain consumed by tests/stories; Index conversation's endpoint admission
is index-specific. The older context display setter has no lease-return API; the
component publishes current context and deliberately does not clear that setter on
teardown, which could erase a newer route's context. Neutral capability cleanup uses
the existing token-aware lease. Current owner tests cover late Index answers across
World, thread and route replacement. This does not generalize admission by config.
