## Selected contract

Preserve the complete original V1 capture and compile a finite catalog from that exact browser editor snapshot before Send. The catalog factors the shared original snapshot once. Each entry includes a stable snapshot-local selector, human label, root boundary/index and editor-compiled position where applicable, and the digest of its complete derived target. Deriving a candidate is deterministic host work, not model work. The browser verifies catalog/snapshot identity before dispatch. No model-authored offsets and no Python implementation of ProseMirror node sizes/UTF-16 positions.

Use dmb_plan_placement_catalog_v1, bound to original_capture_sha256 and editor_sha256. Captured caret/selection/playable replacement remains an exact fixed entry; a replacement selection cannot offer wider replacement/insertion authority. Collapsed caret offers structural before-heading, after-section and end-page entries as well as the current caret. Section labels include hierarchy and duplicate ordinals. The shared table-caption rule excludes caption/table splits. Distinct selectors may intentionally have the same boundary. No arbitrary catalog or label caps.

Use an explicit dmb_plan_authoring_boundary_capture_v1 with target_kind=insert_at_boundary, root_boundary and from=to=editor-compiled root position. It retains the original directional selection as the live-state witness; it does not pretend the root position is a text caret. Other owner/basis/draft/editor/generation fields come unchanged from the original capture. The client validates the root position again from the actual matching ProseMirror document before staging, preview, application and Save. Existing capture V1 stays immutable for retained proposals and exact fixed caret/selection/playable targets. Current Send always supplies the new catalog when a capture exists; there is no fallback current path selecting an incidental caret.

Use requested-work input/authorized/selected V2 and a current placement policy binding the original capture and catalog digests. The single decision offers closed choices discuss, clarify, different_destination, write_unavailable, or write:<offered selector>. Only selectors plus human labels reach the provider; root positions and capture IDs remain host proof. Decode to the existing requested_work meaning plus an exact offered selector; write_unavailable preserves writing intent without running the writer. Ambiguous, missing or contradictory named placements choose inline clarification; no deferred writing executes. Preserve raw actual authorization/result/usage and selection proof.

The selected event binds original capture/catalog digests, offered selector and resolved capture digest. APP checks exact submitted intent, policy, parent request, actual provider and typed response. Reservation binds the resolved target; the immutable action origin's selection event links back to the original capture/catalog proof. Writer projection verifies the same resolved target and supplies a human location label, never free position authority. Terminal result, review and Save retain the exact resolved capture. Do not rewrite the policy's original capture digest to the selected one.

No second browser roundtrip is needed: every offered entry already determines its complete capture before Send. Send-time browser checks, the existing committed-basis/action lock checks, and live client stale refusal protect the boundary. An unsaved edit during inference may leave an inert stale proposal and consume a writer call; it must never mutate/revert that newer draft. A committed basis change fails the existing reservation/writer lock checks. No freshness-only callback, silent recapture or automatic resend.

Add only the required APP target-kind CHECK constraint migration after 0079; no new table, column or proposal store. Boundary insertion is compose, has no selection/playable receipt, and requires the current authoring origin. Keep action/pointer/conversation/turn/content lock order. Historical V1 reading is retained-data preservation, not a selectable compatibility execution route.
