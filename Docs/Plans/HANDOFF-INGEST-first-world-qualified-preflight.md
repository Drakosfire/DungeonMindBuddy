## Invariant and contract

One capability: expose exact native expressibility before sealing and permit an
explicit return to review only on verified request-scoped nonapplication.

1. Add required read-only preflight to WorldGraphInitializationAuthority. Its
   adapter uses the same source mapping, endpoint qualification and command
   construction/validation as initialize, without invoking native initialization
   or reserving/writing anything. No optional legacy method fallback.
2. Prepare rematerializes exact choices and preflights the exact initialization
   request before returning a sealed plan. Failure identifies assertion, typed
   predicate, endpoints/kinds and reason. Preserve choices; never silently filter
   assertions, rewrite predicates or broaden vocabulary.
3. Confirm verifies/rematerializes a retained plan and reads initialization state.
   Matching receipt/initialized target, unreadable storage, unavailable reads or
   unknown outcomes produce no nonapplication proof. For a verified uninitialized
   target, explicit read-only preflight may return a distinct typed proof ONLY
   when inexpressible and initialize was never invoked in this confirm call.
   Scope proof to managed World/native target/initialization ID/plan ID/digest and
   specific validation failure. Do not classify exceptions after initialize began
   as proof. Preserve native pristine-target transaction as final commit authority.
4. Proof says this confirm did not invoke initialization, never that the World
   stays empty forever. A concurrent initialization remains governed by native
   authority; subsequent prepare must re-admit the target. No absence-of-probe,
   generic HTTP status, diagnostic string or transport error can release recovery.
5. UI verifies typed proof and exact retained-plan scope. Offer explicit Return to
   review; clear only owned matching recovery under existing WebLock coordination.
   Preserve source/run and all choices; highlight offending assertion/reason.
   Storage/ownership change refuses release. All uncertain outcomes keep exact
   request recovery and never autorepost/rebase. Preflight rejects are review
   feedback, not accepted/published assertions.
