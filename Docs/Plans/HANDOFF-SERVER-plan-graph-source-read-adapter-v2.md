## Review hold and correction — safe V2 reclaim

PRIME's independent review of `7bb00d8c8427ee6be4674e90647dc9eacde05596` found that an incomplete V2 turn with no authorized provider attempt could not be safely reclaimed: the pinned Graph search made a fresh random retrieval-session ID while the durable V2 source scope kept the original ID. The new route uses deterministic source-session and initial-search operation handles for new V2 turns from managed World, turn ID, and pinned Graph revision, so those handles can be reconstructed after process restart. It reuses an existing same-ID in-memory session without overwriting in-flight state. On retry, SERVER checks current selected metadata against the frozen source pins, restores a preexisting original session when needed for an older random-ID turn, and rejects missing or different original state, changed authority, or any prior provider authorization. V1 retries do not gain the V2 source tool. The provider-envelope digest check remains mandatory and rejects any remaining reconstruction drift.
