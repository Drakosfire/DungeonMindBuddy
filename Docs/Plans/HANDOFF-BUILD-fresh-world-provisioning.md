operation in the same locked registry transaction as source-root creation. The
native identity is also the source KnowledgeSpace ID; the managed slug remains
source/workspace ownership identity. A reservation is not a Graph binding or head.
Source ingestion can use this exact reservation before Graph publication. Graph
reads, existing-Graph bind/deactivate and first publication cannot promote it.
The next serial slice must initialize a real reviewed zero-parent Graph and verify
its receipt before activation. Source KnowledgeSpace genesis cannot stand in for
Graph genesis. Existing unbound records are not allocated or repaired by name.

Retries/restart retain exact IDs. Reserved and active IDs cannot be claimed by
another World. A failed registry write removes only a newly created empty root.
