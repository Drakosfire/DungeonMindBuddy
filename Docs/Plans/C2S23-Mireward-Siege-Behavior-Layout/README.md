# C2S23 Mireward Siege Behavior + Layout Packet

**Status:** Planning artifact. Not corpus-promoted canon.

**Branch anchor:** `cursor/c2s23-mireward-prep-ui`

**Purpose:** Give the GM a queryable model for how Mireward behaves once the north-gate crisis becomes a siege: who takes authority, where panic concentrates, how resources move, where glassy-eyed refugees create moral pressure, what levers the party can pull before the next combat beat, and how the north-gate threat ladder escalates into alien siege pressure.

This packet intentionally stays practical. It is not a full gazetteer. It is a table-facing operating model.

## Locked operator decisions

1. **Tithe barn / tithe compound:** The tithe barn has both an interior and exterior compound footprint. It is not crown-owned; there is no crown. Treat it as a civic / common-reserve institution with clerks, ledgers, stores, and public trust pressure.
2. **Festival commons:** The counter-festival commons are on the **south apron**.
3. **Ferry / causeway:** The ferry-causeway system is **inside the north gate**, crossing an east-west river flowing out of the mountains.
4. **Emergency authority:** Closing or overriding the north gate requires **emergency consensus**, not unilateral authority.
5. **Glassy-eyed first instinct:** Mireward's first instinct is to **treat**, not imprison or execute.
6. **Primary remembered site:** The session should leave the **Bell / Shrine** as the key civic image.
7. **Tripod Null-Calf:** The large three-limbed alien siege scout appears on-screen.
8. **North gate focus:** The later siege breaker focuses the **north gate**, with optional redirection if the party is not challenged.
9. **Bardic escalation:** Bardic counter-music comes when things get dire: **bagpipes out of the morning mist**.
10. **Glassy-eye truth:** Glassy civilians are infected, dreaming, and receiving a signal; they can all be cured if the cure line is protected.
11. **Rest pressure:** Short rest pressure is intentionally harsh.

## Design principles retained

- Mireward is not cowardly. It is underprepared because peace, festival pull, and long patrols made danger feel abstract.
- Mireward is not Mirathorn-lite. Its culture is freer, louder, more anarchic, more anti-authoritarian, and proud of distance from city control.
- The siege is Lovecraftian / civic horror, not only tactical war.
- Refugees are not a faceless mass. Bad counts should create names, contradictions, and moral pressure.
- Glassy civilians create a **protect-the-cure** problem, not an execution problem.
- The party should have meaningful levers beyond fighting monsters.
- Lysandro should translate abstract authority into named-neighbor action.
- Salla, Orric, and Nera should each be right about something and wrong about something.
- The north gate is the tactical focus, but the Bell / Shrine, tithe barn, and ferry chain remain escalation targets if the table needs more pressure.
