## Exact domain meaning and qualifications

- Candidate `precedes`, family `temporal_sequence`, native `dungeonbuddy.custom:precedes` means: this admitted source account places the represented occurrence A earlier than represented occurrence B, at the granularity described by that source. It is strict order of represented occurrence anchors, not an assertion about unrepresented interval starts/ends, calendar dates, elapsed time or causation.
- Do not emit it for unknown order or overlapping represented occurrences. A<C and B<C leave A/B unresolved. Omission represents unsupported order; no total timeline or inferred transitive assertions are generated.
- Occurrences are specific source-described happenings. A person, place, item, persistent topic or paragraph is not an occurrence because its description mentions action. Making/discussing a plan is distinct from the proposed future event. A report can assert source-relative reported order with its retained epistemic qualification; it does not become independent omniscient truth.
- Existing thread/event pass supplies source-grounded event candidates; existing edge pass nominates source-supported precedence. No extra pass, producer, representation, raw-beat projection, vocabulary fork or fallback.
- Machine eligibility: both selected candidate endpoints have event kind and a positively selected source-supported description (whole or exact proper extent). Description-only creates are valid; do not manufacture event classification/name assertions. Existing durable endpoints with admitted incompatible person/place/item classification are refused. Canonical endpoint identity is resolved once at selected-intent compilation; uncertain identity is held, not guessed.
- Semantic review, not string heuristics, owns actual occurrence identity, source entailment, interval/overlap ambiguity, report attribution and planning-versus-future meaning. Event labels/kinds are eligibility hints, not proof. Tests must honestly distinguish machine refusal from supported human-review holds; do not claim an automatic natural-language truth checker.
