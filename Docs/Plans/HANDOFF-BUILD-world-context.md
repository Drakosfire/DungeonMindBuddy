  World, binding version, Graph revision, current turn and policy. Each acquired unit
  has a discriminated origin: primary read/observation or actual World opened passage.
  Never pretend every artifact belongs to the primary page's singleton SourceScope.
- World search/object action selection has its own typed APP event/actual controller
  input-response join; top-level answer/propose/image and Plan events retain meaning.
  Dynamic candidates derive only from current governed results. Attempts, including
  unknown/partial failures, cannot silently repeat or become successful evidence.
- Independently reconstruct selected object operation→its returned anchor/pin→actual
  V2 source-read receipt/body and origin. Foreign World/revision/source/hash, unrelated
  anchor, missing body, stale/late selection or scope drift fails closed.
- Existing final relevance votes and exact selected-event closure keep their meaning.
  Primary artifact_under_edit remains separately authored context. World source claims
  cite only actual producing-writer included V2 receipts, never saved-page read IDs.
  Names come from source owner metadata; names do not grant read/evidence authority.
- Source bodies and semantic facts appear once per actual context lane. Keep opaque
  operational origin proof in host bindings rather than repeating it in Jev prose.
  Existing limits only; no new cap, confidence override, automatic retry or output repair.
- Frozen completed records retain exact historical meaning; new execution uses an
  explicit World-context policy. Preserve proposal/image/Rules routing and drafts.
