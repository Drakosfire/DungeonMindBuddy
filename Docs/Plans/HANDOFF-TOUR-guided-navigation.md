## Request and failure contract
A transient inspection registry is separate from observations. Capture immutable World/walkthrough/index/epoch/bindings plus owner registration identity. Every async owner call receives isCurrent and checks it before presentation mutation. New blocking conditions, restart/back/cross-tab/World changes, unexpected owner unmount/replacement or duplicate registrations invalidate requests. Stable registration tokens survive incidental busy/dirty renders; callbacks and guards stay live in refs. Guided and manual selections share the owner selection generation. Exempt only loading/switching created by that exact owner reservation; post-read draft/persistence/command checks still apply before any presentation publication. Canceled cleanup touches only its own reservation, never a newer selection. Route dispatch ends source departure authority; expected source unmount does not cancel the scoped intent, and a unique destination owner must separately claim and verify it before inspection. No departed-source callback is reused. A second independent critique explicitly approved this refined design direction, not unimplemented code. Cross-surface navigation uses normal same-document navigation only after departure admission; same-surface changes use owner selection. Missing bindings open normal choosers; missing/trashed objects, foreign parents and exact-revision mismatches explain refusal without implicit rebinding. Existing recorded results remain retained. No generic DOM clicking, arbitrary timeout or polling/retry loop.
