## Outcome and boundary

A human can choose and read an exact existing Markdown section of a selected saved
source in the shared World browser. Whole-source reading remains explicit. Reuse
`native_source_catalog.section_catalog`, which is also consumed by native body
acquisition. The existing authenticated source-only `/read` response carries its
section descriptors after Core opens and verifies the exact source. No new route,
source identity, admission authority, body store, provider grant or durable record.

This is the selector prerequisite for the next serial Build attachment slice.
The browser currently returns only whole text; the request/Turn contracts currently
capture objects only. Keep the durable request/acquisition change separately
reviewable rather than adding an unread or unexercised attachment button here.

## Invariants and retirement

Core alone decides whether the full source can be opened. Catalogue browsing
still reads no bodies. Source/session filters remain navigation, not restriction.
The section identity uses the exact source pair, hash and line interval from the
existing owner. Preserve Python character offsets across astral Unicode in JS;
UTF-16 slicing is not an equivalent selector. Wire validation checks actual native
line/code-point boundaries (including Python splitlines separators); it does not
reparse Markdown in the UI. Core-admitted whitespace-only bodies remain readable
with an explicitly null section catalogue because the selector requires nonblank text.
Reject invalid descriptors and reset passage selection on source, revision, World,
refresh or failed opening. A section that covers the entire body is whole-source
exposure, not a smaller passage. Display exact lines and selector in version info.

Adopt the shared selector and existing renderer. There is no prior human passage
selector to delete. Retain existing retrieval and historical readers; this slice
must not add a second parser, executor, evidence ledger or chronology framework.

selector, including Unicode/CRLF/fenced headings, revision stability and foreign
selector refusal. UI tests exercise exact selected text, duplicate labels,

selection reset. Re-run relevant source browser/auth/Graph tests and type/build;
