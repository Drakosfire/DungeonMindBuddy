## Contract

One retained operation UUID and exact sealed intent reserve one registered Build page UUID before creation. The request retains selected source document/loaded revision/hash, editor JSON and its hash, exact quote and ProseMirror selection coordinates. There is no parallel caller-supplied Markdown representation to disagree with the editor snapshot. Server verifies source ownership and initial loaded revision/hash, validates the retained JSON/hash, and derives the quote directly from the selection range using ProseMirror UTF-16 coordinates. The first adapter accepts a nonempty range wholly within a text-only paragraph/heading (including marks); unsupported or inconsistent captures refuse before page creation. Client capture fences the actual current editor/selection; mounted UI tests must prove that boundary in slice three. The origin is always labeled a captured working copy with its saved base, never certified as saved bytes. Native publication evidence is the new page’s independently committed declaration, not this working capture. Never reinterpret editor offsets as Markdown offsets, save Edge, navigate on the server, replace its text or publish captured working text as a committed source.

The visible client review chooses exact new/reused location and optional person plus directed predicates. For Brin, the operator declared both owns and operates; person identity remains explicit. Existing node IDs, canonical labels and kinds must resolve in the managed World's native projection before preparation. New identities are explicit declarations. No fuzzy identity merge, label-only reuse or silent endpoint substitution. Initial page includes an ordinary origin link/quote, explicit relationship declarations and editable scaffold/blanks; mode Scaffold/Build out and clarifying answers are retained. Generation is a later UI slice using the existing writer; this operation makes no inference calls.

Prepare reserves the operation/page, creates that exact page, durably saves its initial declaration via the existing Tiptap writer, then prepares a native object/relationship bundle using the new exact document source selector. The page has committed bytes with draft story authority. The client shows the semantic review before choosing Create; prepare never publishes graph assertions. Confirm requires the retained operation's exact signed graph request, preserves existing native binding/parent/idempotency rules and stores receipt plus page↔location association. Partial creation/publication is recoverable and never reported complete before native acknowledgement. Native uncertainty retries the same sealed confirmation, not a new preview or page. Extend the existing confirmation owner so a valid signed but expired intent may recover an already-published exact receipt after all payload/source/World/contribution checks. Expiry still forbids every fresh publish: when no receipt exists, return confirmation_expired before current-head/publish calls. No re-prepare of an uncertain operation. An expired unexecuted intent remains a truthful actionable partial page; a changed/reviewed intent requires a deliberate new operation. A changed operation payload conflicts.

Registry record stores immutable originating operation ID, enabling page reopen to find its retained operation and native associations. The reserved page ID is internal service authority, absent from generic HTTP create request. Retry recognizes an already-created/initially-saved page after response loss and does not overwrite later edits; unknown changed initial-save outcomes remain actionable with the page retained. No compensating deletion or rollback of author content. Operation state lives in server-owned private registry files under the configured artifact root, serialized with file locks and atomic durable writes. World/source ownership is revalidated for recovery; later source text edits do not erase the origin capture.
