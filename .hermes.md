# DungeonMindBuddy Hermes Harness Policy

DungeonMindBuddy is the source of truth for campaign corpus, evidence, facts, canon layers, projections, and continuity checks.

Hermes is only the conversation and tool orchestration layer.

## Hard Rules

- Do not treat Hermes memory as campaign canon.
- Do not invent campaign facts when DungeonBuddy tools return no evidence.
- Always prefer DungeonBuddy tools over ambient memory, context files, or freeform reasoning for campaign questions.
- Use tool results as evidence bundles, not as final answers.
- Preserve uncertainty.
- Distinguish world, campaign, play, and planning layers when tool results include layer metadata.
- Do not mutate canon unless the user explicitly asks for a write operation and a DungeonBuddy write tool exists.
- Do not store campaign facts, canon facts, session facts, NPC state, or worldbuilding details in Hermes memory.

## Initial Tool Policy

For corpus questions:

1. Call `dungeon_search`.
2. Inspect returned evidence.
3. If needed, call `dungeon_get_document` on high-value documents.
4. Answer from the evidence only.
5. State when evidence is missing, ambiguous, or conflicting.

For continuity questions:

1. Call `dungeon_check_continuity`.
2. Report exact matches, near matches, conflicts, and unknowns separately.

For future DungeonMind tools:

- Mock tools may be used for planning behavior, but mock results must be labeled as mock results.

## Plugin enablement

General plugins are discovered by Hermes but must be explicitly enabled (`plugins.enabled` / `hermes plugins enable dungeonbuddy`). Use a dedicated `HERMES_HOME` (for example `$PWD/.hermes-runtime` from this repo) so spike config does not pollute your default Hermes profile.

## Symlink and enable (this repo)

From the DungeonMindBuddy repo root (requires [Hermes](https://github.com/NousResearch/hermes-agent) on your `PATH`):

```bash
export HERMES_HOME="$PWD/.hermes-runtime"
export DUNGEONBUDDY_REPO="$PWD"
export DUNGEONBUDDY_CORPUS_ROOT="$PWD/corpus"
mkdir -p "$HERMES_HOME/plugins"
ln -sfn "$PWD/integrations/hermes/plugins/dungeonbuddy" "$HERMES_HOME/plugins/dungeonbuddy"
hermes plugins enable dungeonbuddy
```

Or run `./scripts/hermes_spike_install_plugin.sh` after the same `export` lines.

Chat smoke: `hermes chat --toolsets "dungeonbuddy,memory,file"`. Prefer `hermes memory off` for this spike.

Spike question list (manual eval): `evals/hermes_spike/questions.jsonl`.
