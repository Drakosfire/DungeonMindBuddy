## Read order

Corpus root: `DungeonMindBuddy/corpus/eldyrwild-markdown/`.

1. **`caelynn_character_dossier.md`** — Identity, **comms (call sign: The Storm)**, relationships, tools/items/spells **as named in recaps**, arc hooks from `Campaign 2 Notes.md`, and a curated “where to read next” table.

3. **`Campaign 2 Notes.md`** — Party-wide threads and per-player goal bullets.
4. **`NPCs/captain_lysandra_ironveil/`** — Parallel hub for Lysandra, heavily intertwined with Caelynn’s through-line.

For deep lore hooks that extend beyond recap prose, see `Elderwyld_Narrative_Ledger_Campaign2.md` (e.g. **Stormbark tea**, **father quest**, **Tealeaf** fungi thread).
