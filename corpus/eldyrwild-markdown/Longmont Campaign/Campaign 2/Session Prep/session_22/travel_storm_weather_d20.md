# Storm weather d20 (T-WX)

**Use:** Roll **once per march day** (beats 1–3) **before** T-NPC — step 1 in runbook §7. At **Mireward arrival** (beat 4), roll once for gate weather or pick a row that fits §3.7 (squall, mud queue, brittle clear).

**Canon hook:** Session 21 edge storm — savory/shimmer rain, magic sheen in pools, front **building west**. This table is **texture and agency**, not a second road encounter.

**Row shape:** `{headline} · {sensory} · {spark} · {if ignored / repeat}`

**Repeat rule:** Same row twice on one journey → the phenomenon **follows longer** (same distance west on the horizon, same smell in every camp, static that learns their names). Still not chasing. Obviously.
