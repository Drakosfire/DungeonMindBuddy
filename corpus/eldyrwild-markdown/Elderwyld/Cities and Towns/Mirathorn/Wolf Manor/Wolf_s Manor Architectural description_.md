# 📐 Conventions (read first)

Grid: 5-ft squares.

Orientation: **North is up**. Coordinates (x,y) in squares measured from the **south-west exterior corner of the manor** (not the grounds). So the manor’s SW exterior corner is (0,0).

Doors: interior single door = 1 square (5 ft) wide unless noted; double = 2 squares (10 ft).

Walls: assume ~1 ft thickness within the room footprint; on-grid we treat walls as the **edge** of a room polygon unless noted as **thick masonry** (then occupy 1 square).

Windows: 3–5 ft wide—treat as centered on a wall segment; I’ll specify locations in squares.

Stairs: each stair run occupies the squares listed; unless noted, stairs rise **northward**; each full flight changes floor level by one story.

Levels listed: **Grounds (site plan)** → **Floor 1** → **Floor 2** → **Floor 3 (Conservatory & Observatory)** → **Cellar/Basement & Tunnels**.
