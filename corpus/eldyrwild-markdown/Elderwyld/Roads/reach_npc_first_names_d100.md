# d100 First Names — Mireward Reach

## How to use

- Roll **d100** here for a first name, then roll **T-NAME-L** in `reach_npc_last_names_d100.md`.
- Use the row's **Region** as a quick cultural accent, not a fixed birthplace. A Mirathorn-tagged guard can still be posted north.
- If the party is within **two days** of a named anchor, you may reroll once if the region feels wrong: Mirathorn / Mossford / Mireward / Edge-Fen.
- Use the **Scaffold** as the person's first playable handle: job, pressure, and voice direction.
- For R5 strangers, gate pressure, refugee queues, comms overhear, or courier traffic, roll both tables before improvising the scene.
- Repeat rule: if the same first + last pair appears twice on one journey, add a distinguisher — nickname, limp, uniform patch, smell, "the younger," or a visible trade tool.
- Reserved names are intentionally absent; do not use these rows to rename established PCs, NPCs, or working anchors.
- A useful stranger is still a valid random result. Not every name belongs to a threat.
